## 🔄 **Yapılması Gerekenler:**

### 1. **Google Search Console Kurulumu:**
1. [Google Search Console](https://search.google.com/search-console/) → "Özellik Ekle"
2. Domain: `itirafpazari.com` ekle
3. Doğrulama: HTML meta tag (zaten var)
4. Sitemap gönder: `https://itirafpazari.com/sitemap.xml`

### 2. **Google Analytics Kurulumu:**
1. [Google Analytics](https://analytics.google.com/) hesabı oluştur
2. Tracking ID'yi al (G-XXXXXXXXXX)
3. `.env` dosyasına ekle: `NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX`

### 4. **Teknik SEO:**

### 5. **Backlink ve Tanıtım:**

## 📊 **Beklenen Süreçler:**

### **Google İndexleme:**
- **İlk indexleme**: 1-7 gün
- **Düzenli tarama**: 1-4 hafta
- **Ranking iyileşmesi**: 3-6 ay

### **Hızlandırma Yöntemleri:**
1. **URL İnceleme**: Search Console → URL İnceleme → "Canlı URL'yi test et"
2. **Manuel İndexleme**: "İndexleme iste" butonuna tıkla
3. **Sosyal Paylaşım**: Twitter, Facebook'ta paylaş
4. **Backlink**: Diğer sitelerden link al
